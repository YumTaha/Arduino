# Arduino Sketch Collection

Small Arduino projects for learning microcontroller programming, sensor input, and output devices.

## Projects

| Folder | Focus |
| --- | --- |
| [`1-Display/`](1-Display/) | Display experiments |
| [`Blink/`](Blink/) | LED blinking |
| [`Fade/`](Fade/) | LED fading |
| [`DHT/`](DHT/) | Temperature and humidity sensing |
| [`PIR/`](PIR/) | Motion sensing |
| [`UltraSonic/`](UltraSonic/) | Ultrasonic distance sensing |

## Getting started

1. Clone this repository or download it as a ZIP.
2. Open a sketch from one of the project folders in the Arduino IDE.
3. Check the sketch for its pin assignments and required libraries before wiring the circuit.
4. Select the board and serial port that match your hardware, then compile and upload.

Each folder is a separate experiment; there is no single application to build at the repository root.
